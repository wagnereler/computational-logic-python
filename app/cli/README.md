# CLI

Responsabilidade: menu acadêmico interativo e apresentação no terminal. Pode usar `while`, `if/elif/else`, `for`, `input`, `print`, exceções e `break`. Não deve conter SQL nem regras de validação de produto. Depende de ProdutoService e inicialização técnica do banco. Correto: `_add` lê campos e chama `service.create`. Incorreto: validar duplicidade consultando SQLite na CLI.
